Functions That Learn Functions 関数を学ぶ関数

Probability, representation, and search in neural networks. ニューラルネットワークにおける確率・表現・探索

This book explains how a neural network learns a probability distribution, rather than a single answer. Every idea first appears as a picture you can play with. A name and a formula come only after that.

この本では、ニューラルネットワークが一つの答えではなく確率分布をどう学ぶのかを説明します。どの考え方も、まず手で動かせる図として登場します。名前や数式が出てくるのはその後です。

Two running examples全章を通して使う2つの例

  • Rain vs. no rain. Given today's humidity $h\in[0,1]$, will it rain? The true chance is $p(\text{rain}\mid h)=\sigma(12h-7.2)$.
  • 雨か晴れか。今日の湿度 $h\in[0,1]$ から、雨が降るかを予測します。真の確率は $p(\text{雨}\mid h)=\sigma(12h-7.2)$ です。
  • Noisy curve. $y=\sin x+\varepsilon$ with $\varepsilon\sim\mathcal N(0,0.3^2)$.
  • ノイズのある曲線。$y=\sin x+\varepsilon$、ただし $\varepsilon\sim\mathcal N(0,0.3^2)$ です。

How each chapter works各章の進め方

  1. Puzzle: a question about the running examples.
  2. パズル：例題についての問いから始めます。
  3. Predict: guess the answer before touching anything.
  4. 予想：図を触る前に、答えを予想します。
  5. Play: drag, slide, and watch what changes.
  6. 操作：ドラッグやスライダーで、何が変わるかを観察します。
  7. Name it: the formal definition, now that you have seen it.
  8. 名前をつける：実際に見たあとで、正式な定義を与えます。
  9. Check and bridge: a short check, then the question that opens the next chapter.
  10. 確認と橋渡し：短い確認問題を解き、次の章につながる問いを示します。
