Proof Sketches証明のスケッチ

Short arguments for the main claims, in the order they appear. Open each one when you want it.

本文の主な主張についての短い議論を、登場順に並べました。必要なときに開いてください。

C.1 Gibbs' inequality: $D_{KL}(p\|q)\ge 0$ (Ch. 2)C.1 ギブスの不等式：$D_{KL}(p\|q)\ge 0$（第2章）

Use $\ln t\le t-1$, with equality only at $t=1$. Sum over $y$ with $p(y)>0$:

$\ln t\le t-1$（等号は $t=1$ のときのみ）を使います。$p(y)>0$ となる $y$ について和をとると：

$$-D_{KL}(p\|q)=\sum_y p(y)\ln\frac{q(y)}{p(y)}\;\le\;\sum_y p(y)\Big(\frac{q(y)}{p(y)}-1\Big)=\sum_{y:\,p(y)>0} q(y)-1\;\le\;0.$$

Equality requires $q(y)/p(y)=1$ wherever $p(y)>0$, that is, $q=p$. ∎

等号が成り立つには、$p(y)>0$ となるすべての $y$ で $q(y)/p(y)=1$、つまり $q=p$ でなければなりません。∎

C.2 Maximum likelihood = minimum cross-entropy = minimum KL (Ch. 2)C.2 最尤推定 = 交差エントロピー最小化 = KL 最小化（第2章）

Let $\hat p=\frac1n\sum_i\delta_{y_i}$ be the empirical distribution. Then

$\hat p=\frac1n\sum_i\delta_{y_i}$ を経験分布とします。すると

$$-\frac1n\sum_i\log q(y_i)=-\sum_y\hat p(y)\log q(y)=H(\hat p,q)=H(\hat p)+D_{KL}(\hat p\|q).$$

$H(\hat p)$ does not depend on $q$, so all three objectives have the same minimizer. As $n\to\infty$, the law of large numbers replaces $\hat p$ by $p$. ∎

$H(\hat p)$ は $q$ によらないので、3つの目的関数の最小点は同じです。$n\to\infty$ とすると、大数の法則によって $\hat p$ が $p$ に置き換わります。∎

C.3 Squared error is Gaussian log-loss (Ch. 2)C.3 二乗誤差はガウスの対数損失（第2章）

$$-\ln\mathcal N(y\mid\mu,\sigma^2)=\frac{(y-\mu)^2}{2\sigma^2}+\ln\sigma+\tfrac12\ln 2\pi.$$

For fixed $\sigma$, minimizing the average over data in $\mu$ is minimizing $\frac1n\sum_i(y_i-\mu_i)^2$. ∎

$\sigma$ を固定すれば、データ上の平均を $\mu$ について最小化することは、$\frac1n\sum_i(y_i-\mu_i)^2$ を最小化することと同じです。∎

C.4 Risk decomposes into noise + KL (Ch. 4)C.4 リスクはノイズ + KL に分解できる（第4章）

$$R(\theta)=\mathbb E_x\,\mathbb E_{y\sim p(\cdot\mid x)}\big[-\log q_\theta(y\mid x)\big]=\mathbb E_x\Big[H\big(p(\cdot\mid x)\big)+D_{KL}\big(p(\cdot\mid x)\,\|\,q_\theta(\cdot\mid x)\big)\Big].$$

Apply C.2 inside the expectation over $x$. The first term is the irreducible floor, and the second is zero only if $q_\theta(\cdot\mid x)=p(\cdot\mid x)$ for almost every $x$. ∎

$x$ についての期待値の内側で C.2 を適用します。第1項は取り除けない床で、第2項が0になるのは、ほとんどすべての $x$ で $q_\theta(\cdot\mid x)=p(\cdot\mid x)$ のときだけです。∎

C.5 Universal approximation in 1-D (Ch. 6)C.5 1次元の普遍近似（第6章）

Let $g$ be continuous on $[a,b]$ and $\varepsilon>0$. Since $g$ is uniformly continuous, choose knots $a=k_0<\dots<k_N=b$ so close that the piecewise-linear interpolant $\ell$ through $(k_j,g(k_j))$ satisfies $|g-\ell|<\varepsilon$. Any such $\ell$ is exactly a one-hidden-layer ReLU network:

$g$ を $[a,b]$ 上の連続関数、$\varepsilon>0$ とします。$g$ は一様連続なので、結び目 $a=k_0<\dots<k_N=b$ を十分細かく取れば、$(k_j,g(k_j))$ を通る区分線形な補間 $\ell$ が $|g-\ell|<\varepsilon$ を満たすようにできます。そのような $\ell$ は、ちょうど隠れ層1つの ReLU ネットワークになっています：

$$\ell(x)=g(a)+\sum_{j=0}^{N-1}c_j\,\mathrm{ReLU}(x-k_j),\qquad c_j=s_j-s_{j-1},\ s_{-1}=0,$$

where $s_j$ is the slope on $[k_j,k_{j+1}]$. In higher dimensions the same idea works with “bump” functions built from several units (or with Fourier/Stone–Weierstrass arguments for sigmoids). ∎

ここで $s_j$ は $[k_j,k_{j+1}]$ での傾きです。高次元でも、複数のユニットで作った「こぶ」関数を使えば同じ考え方が通用します（sigmoid の場合はフーリエ解析や Stone–Weierstrass の議論を使います）。∎

C.6 Depth doubles pieces (Ch. 8)C.6 深さは線分を倍にする（第8章）

The tent $t(x)=2\,\mathrm{ReLU}(x)-4\,\mathrm{ReLU}(x-\tfrac12)$ maps each half of $[0,1]$ linearly onto all of $[0,1]$. So if $t^{\circ L}$ has $2^L$ linear pieces, each mapping onto $[0,1]$, then composing once more splits each piece in two, giving $2^{L+1}$. Meanwhile, a one-hidden-layer ReLU network with $m$ units on a 1-D input is linear between at most $m$ breakpoints, so it has at most $m+1$ pieces. Representing $t^{\circ L}$ exactly therefore needs $m\ge2^L-1$ units, against $2L$ for the deep version. ∎

テント $t(x)=2\,\mathrm{ReLU}(x)-4\,\mathrm{ReLU}(x-\tfrac12)$ は、$[0,1]$ の左右の半分をそれぞれ $[0,1]$ 全体に線形に写します。したがって $t^{\circ L}$ が $2^L$ 本の線分を持ち、そのそれぞれが $[0,1]$ 全体に写るなら、もう一度合成すると各線分が2つに分かれ、$2^{L+1}$ 本になります。一方、1次元の入力に対する隠れ層1つ・$m$ ユニットの ReLU ネットワークは、最大 $m$ 個の折れ点の間でしか線形でないので、線分は最大 $m+1$ 本です。よって $t^{\circ L}$ を正確に表現するには $m\ge2^L-1$ ユニットが必要で、深いほうは $2L$ ユニットで済みます。∎

C.7 Bias–variance decomposition (Ch. 8)C.7 バイアス–バリアンス分解（第8章）

Let $y=f(x)+\varepsilon$ with $\mathbb E\varepsilon=0$ and $\operatorname{Var}\varepsilon=\sigma^2$, and let $\hat f_D$ be fitted on a random dataset $D$. At a fixed $x$, write $\bar f=\mathbb E_D\hat f_D(x)$. Then

$y=f(x)+\varepsilon$（$\mathbb E\varepsilon=0$、$\operatorname{Var}\varepsilon=\sigma^2$）とし、$\hat f_D$ をランダムなデータセット $D$ で当てはめたものとします。$x$ を固定し、$\bar f=\mathbb E_D\hat f_D(x)$ と書くと

$$\mathbb E_{D,\varepsilon}\big[(y-\hat f_D(x))^2\big]=\underbrace{\sigma^2}_{\text{noise}}+\underbrace{(f(x)-\bar f)^2}_{\text{bias}^2}+\underbrace{\mathbb E_D(\hat f_D(x)-\bar f)^2}_{\text{variance}}.$$

Expand the square around $f(x)$ and $\bar f$. The cross terms vanish because $\mathbb E\varepsilon=0$ and $\mathbb E_D(\hat f_D-\bar f)=0$. ∎

$f(x)$ と $\bar f$ のまわりで2乗を展開します。$\mathbb E\varepsilon=0$ かつ $\mathbb E_D(\hat f_D-\bar f)=0$ なので、交差項は消えます。∎

C.8 Gradient descent on a quadratic (Ch. 10)C.8 2次関数上の勾配降下法（第10章）

For $L(\theta)=\tfrac12\theta^\top A\theta$ with eigenvalues $0<c_1\le\dots\le c_d$, the update is $\theta_{k+1}=(I-\eta A)\theta_k$. Along eigenvector $j$ the error is multiplied by $1-\eta c_j$ each step. It shrinks iff $|1-\eta c_j|<1$, that is, $\eta<2/c_j$. So the steepest direction caps $\eta<2/c_d$, while the flattest one converges at rate $1-\eta c_1\ge1-2c_1/c_d$. Ravines (large $c_d/c_1$) are slow. ∎

固有値が $0<c_1\le\dots\le c_d$ である $L(\theta)=\tfrac12\theta^\top A\theta$ では、更新は $\theta_{k+1}=(I-\eta A)\theta_k$ です。固有ベクトル $j$ の方向では、誤差が1歩ごとに $1-\eta c_j$ 倍されます。これが縮むのは $|1-\eta c_j|<1$、つまり $\eta<2/c_j$ のときだけです。したがって最も急な方向が $\eta<2/c_d$ という上限を課し、最も平らな方向は $1-\eta c_1\ge1-2c_1/c_d$ の割合でしか収束しません。峡谷（$c_d/c_1$ が大きい）が遅いのはこのためです。∎

C.9 The softmax gradient is $q-y$ (Ch. 10)C.9 softmax の勾配は $q-y$（第10章）

With $q_k=e^{z_k}/\sum_j e^{z_j}$ and one-hot $y$, the loss is $-\log q_c=-z_c+\log\sum_j e^{z_j}$. Differentiating:

$q_k=e^{z_k}/\sum_j e^{z_j}$、$y$ を one-hot とすると、損失は $-\log q_c=-z_c+\log\sum_j e^{z_j}$ です。微分すると：

$$\frac{\partial}{\partial z_k}\big(-\log q_c\big)=-[k=c]+\frac{e^{z_k}}{\sum_j e^{z_j}}=q_k-y_k.\quad\blacksquare$$

At a stationary point of the average loss, $\sum_i(q_i-y_i)\,\nabla_\theta z_i=0$. For a linear last layer on features $h_i$, this says $\sum_i q_ih_i=\sum_iy_ih_i$: the model's expected feature totals match the data's (moment matching).

平均損失の停留点では $\sum_i(q_i-y_i)\,\nabla_\theta z_i=0$ が成り立ちます。特徴 $h_i$ の上に線形の最終層があるなら、これは $\sum_i q_ih_i=\sum_iy_ih_i$、つまりモデルが期待する特徴の合計がデータのものと一致する、ということです（モーメント一致）。

C.10 Gradient descent from zero finds the minimum-norm fit (Ch. 12)C.10 0から出発した勾配降下法は最小ノルムの当てはめを見つける（第12章）

For least squares $\|Xw-y\|^2$ with more features than points, every gradient $2X^\top(Xw-y)$ lies in the row space of $X$. Starting from $w_0=0$, every iterate stays in that row space. The only interpolating solution in the row space is $w^\star=X^\top(XX^\top)^{-1}y$, which is the one with the smallest norm. ∎

点より特徴のほうが多い最小二乗法 $\|Xw-y\|^2$ では、どの勾配 $2X^\top(Xw-y)$ も $X$ の行空間に入っています。$w_0=0$ から出発すれば、どの反復もその行空間にとどまります。行空間の中でデータを補間する解は $w^\star=X^\top(XX^\top)^{-1}y$ ただ1つで、これがノルム最小の解です。∎

C.11 Log-loss and Brier are proper (Ch. 2, 12)C.11 対数損失と Brier は適切なスコア（第2章・第12章）

If the truth is Bernoulli($p$) and you announce $r$: the expected log-loss is $H(p)+D_{KL}(p\|r)$, minimized only at $r=p$ by C.1. The expected Brier score is $p(1-r)^2+(1-p)r^2=(r-p)^2+p(1-p)$, also minimized only at $r=p$. ∎

真実が Bernoulli($p$) で、あなたが $r$ を発表するとします。期待対数損失は $H(p)+D_{KL}(p\|r)$ で、C.1 より $r=p$ のときだけ最小になります。期待 Brier スコアは $p(1-r)^2+(1-p)r^2=(r-p)^2+p(1-p)$ で、これも $r=p$ のときだけ最小になります。∎
