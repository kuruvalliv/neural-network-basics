Functions as Objects対象としての関数

What does it mean to treat a function as a thing we can search over?関数を「探索できるもの」として扱うとはどういうことか？

Chapter 2 ended with: find the $q$ with the lowest loss. Finding a number with the lowest value is easy to picture: slide along a line. But how do you slide along curves? Can choosing a whole curve be as simple as choosing a point on a map?

第2章は「損失が最小の $q$ を見つけよ」で終わりました。値が最小の数を見つけるのは想像しやすく、数直線の上を滑っていけばよいだけです。では、曲線の上を滑るにはどうすればよいのでしょうか。曲線を1本まるごと選ぶことを、地図の上で1点を選ぶのと同じくらい簡単にできるでしょうか。

  • See a function as one complete object (a list of input–output pairs), not as a formula.
  • Recognize that a distribution is a function, and a conditional distribution is a function that returns functions.
  • Use parameters as coordinates that turn “pick a function” into “pick a point”.
  • Recognize functionals (entropy, KL, loss) as machines from functions to numbers.
  • 関数を、式ではなく1つの完全な対象（入力と出力の組の一覧）として見る。
  • 分布は関数であり、条件付き分布は「関数を返す関数」であると理解する。
  • パラメータを座標として使い、「関数を選ぶ」ことを「点を選ぶ」ことに変える。
  • 汎関数（エントロピー、KL、損失）を、関数から数への機械として理解する。

3.1 A function is its whole table3.1 関数とは、その表全体のこと

We usually meet functions as formulas, like $\sigma(12h-7.2)$. A formula is only a recipe, though. The function itself is the full pairing of every input with its output, and a table, a set of arrows, and a graph are three ways to draw it.

関数にはふつう、$\sigma(12h-7.2)$ のような式として出会います。しかし式はレシピにすぎません。関数そのものは、すべての入力とその出力の対応全体です。表・矢印・グラフは、それを描く3つの方法です。

A function $f:X\to Y$ assigns exactly one output $f(x)\in Y$ to every input $x\in X$. A distribution $q$ over outcomes $\mathcal Y$ is a function $q:\mathcal Y\to[0,\infty)$ whose outputs sum (or integrate) to 1.

関数 $f:X\to Y$ は、すべての入力 $x\in X$ にちょうど1つの出力 $f(x)\in Y$ を割り当てます。結果の集合 $\mathcal Y$ の上の分布 $q$ は、出力の合計（または積分）が1になる関数 $q:\mathcal Y\to[0,\infty)$ です。

3.2 Functions that return functions3.2 関数を返す関数

In Chapter 1 we met $p(y\mid h)$: for each humidity, a distribution over weather. Read it as a machine. Put in a number $h$, and out comes a function of $y$. This is the central object of the whole book.

第1章で $p(y\mid h)$ に出会いました。湿度ごとの、天気についての分布です。これを機械として読んでみましょう。数 $h$ を入れると、$y$ の関数が出てきます。これがこの本全体の中心となる対象です。

In the noisy-curve example, what changes about the output distribution as x moves: its location, its width, or both?ノイズのある曲線の例で、x を動かすと出力の分布の何が変わるでしょうか。位置、幅、それとも両方？

Only its location. The center follows $\sin x$, while the width stays $\sigma=0.3$ everywhere. Real data often has a width that changes too. A good model must then output both numbers.

位置だけです。中心は $\sin x$ に沿って動き、幅はどこでも $\sigma=0.3$ のままです。現実のデータでは幅も変わることがよくあります。その場合、よいモデルは両方の数を出力しなければなりません。

$$x\;\longmapsto\;p(\cdot\mid x)\qquad\text{type: } X\to(\mathcal Y\to[0,\infty)).$$

A conditional distribution is a function whose outputs are distributions.

条件付き分布とは、出力が分布である関数のことです。

3.3 Parameters turn functions into points3.3 パラメータは関数を点に変える

The space of all functions is far too big to search. So we fix a recipe with a few blanks, such as $f(x)=a\sin x+b$. Filling in the blanks picks one function. The blanks $\theta=(a,b)$ are parameters, and every function in the family now has an address: a point in the $(a,b)$ plane.

すべての関数の空間は大きすぎて探索できません。そこで、$f(x)=a\sin x+b$ のように空欄をいくつか持つレシピを1つ決めておきます。空欄を埋めると関数が1つ選ばれます。空欄 $\theta=(a,b)$ がパラメータで、関数族の中のどの関数にも、$(a,b)$ 平面上の1点という住所ができます。

A parametric family is a map $\theta\mapsto f_\theta$ from a parameter space $\Theta\subseteq\mathbb R^d$ into a function space. A neural network is a parametric family with a very large $d$.

パラメトリックな関数族とは、パラメータ空間 $\Theta\subseteq\mathbb R^d$ から関数空間への写像 $\theta\mapsto f_\theta$ のことです。ニューラルネットワークは、$d$ がとても大きいパラメトリックな関数族です。

“Each parameter vector is a different function.” Not necessarily. Different addresses can point to the same house.

「パラメータのベクトルが違えば、関数も違う」とは限りません。違う住所が同じ家を指すこともあります。

3.4 Functionals: scoring a whole function3.4 汎関数：関数まるごとを採点する

To search, we need to score each candidate. The score has to look at the entire function, not just one value. A map from functions to numbers is called a functional. You already know several: mean, entropy, KL, and the average log-loss.

探索するには、候補それぞれを採点する必要があります。その採点では、1つの値だけでなく関数全体を見なければなりません。関数から数への写像を汎関数と呼びます。すでにいくつか知っているはずです。平均、エントロピー、KL、そして平均対数損失です。

$$\mathcal L:\;q\;\longmapsto\;\frac1n\sum_{i=1}^n-\log q(y_i\mid x_i)\in\mathbb R.$$

Combined with a parametrization, the functional becomes an ordinary function of $\theta$: $\;L(\theta)=\mathcal L(q_\theta)$. That is something we can minimize.

パラメータ化と組み合わせると、この汎関数は $\theta$ のふつうの関数になります：$\;L(\theta)=\mathcal L(q_\theta)$。これなら最小化できます。

Parameters give every function in a family an address. A functional gives every function a score. Together they turn “find the best function” into “find the lowest point on a map”.

パラメータは関数族のすべての関数に住所を与え、汎関数はすべての関数に点数を与える。この2つを合わせると、「最良の関数を見つける」問題は「地図上で最も低い点を見つける」問題になる。

What is the type of $x\mapsto q(\cdot\mid x)$? What is the type of KL?$x\mapsto q(\cdot\mid x)$ の型は何でしょうか。KL の型は？

The first takes an input and returns a distribution (a function). KL takes two distributions and returns a number, so it is a functional.

前者は入力を受け取り、分布（つまり関数）を返します。KL は2つの分布を受け取って数を返すので、汎関数です。

We now have functions-returning-functions, parameters, and functionals. A neural network combines all three, and it is easy to lose track of which level is which. What exactly does the network output? → Chapter 4

これで「関数を返す関数」「パラメータ」「汎関数」がそろいました。ニューラルネットワークはこの3つすべてを組み合わせたもので、どれがどのレベルの話なのかを見失いがちです。ネットワークは正確には何を出力しているのでしょうか。→ 第4章
